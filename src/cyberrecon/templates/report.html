4. Standards Interpretation

Where applicable, CyberRecon findings may contain CWE and OWASP mappings to help classify the observed condition. These mappings provide context for the finding and should not be interpreted as proof that the target contains a fully exploitable vulnerability. Confidence represents CyberRecon's confidence in the observed condition based on the available passive evidence, not the probability of successful exploitation.

5. Assessment Scope

CyberRecon currently performs passive assessment using DNS resolution, controlled HTTP/HTTPS requests, response metadata collection, security-header inspection, cross-origin configuration observation, selected cookie attribute checks and passive security-rule analysis. The assessment does not perform brute-force attacks, credential testing, destructive payloads or exploitation. Assessments should only be performed against targets owned by the user or targets for which explicit authorization has been obtained.
